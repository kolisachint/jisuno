# Jisuno: app UI (visual and behavior spec)

Status: signed off 2026-11-26 (round 6, `jisuno.md` §10). Prototype `prototypes/v3.html` signed off with it.
Last update: 2026-11-26 (round 6). Prototype: `prototypes/v3.html` (clickable picture of this spec).
Sources: `jisuno.md`, `keybindings.md`, `voice-control.md` (signed off 2026-11-26). Where this doc
and a signed-off doc differ, the signed-off doc wins; the differences were listed in §11 and are resolved there.

## 0. Principles

1. One cue, not chrome: the HUD shows what the user needs now, then gets out of the way.
2. Exact copy: every string below is the string the app shows. Code does not paraphrase.
3. Mode is never colour alone: each mode has a text label (`Dictate`, `Command`) and its own glyph state.
4. Quiet first: inkuno's Quiet look; Jisuno adds two accents and nothing else.
5. Native behaviour: system Settings deep links, Reduce Motion and VoiceOver respected.

### 1.2 Type

macOS system fonts, nothing bundled (round 6). SF Pro for UI text (`-apple-system`, `SF Pro Text`),
SF Mono for code, paths and key caps (`ui-monospace`, `SF Mono`). No font files ship with the app.

| Role | Size / line | Weight | Used for |
|--|--|--|--|
| `display` | 20 / 26 | semibold | Welcome title |
| `title` | 15 / 22 | semibold | pane titles, popover app name |
| `body` | 13 / 18 | regular | rows, popover items, HUD text |
| `label` | 13 / 18 | medium | row labels, buttons |
| `caption` | 12 / 16 | regular, `soft` | hints, status lines, HUD notes |
| `micro` | 11 / 14 | medium, caps, +0.05 em | section labels, HUD mode label |
| `mono` | 12 / 18 | regular | JSON, paths, the countdown |
| `kbd` | 11 / 14 | mono | key caps |

The HUD mode label is set in caps by style; the string is `Dictate` or `Command`.

### 1.3 Spacing, size, radii, elevation

- Grid: 4 px. Steps: 2, 4, 6, 8, 12, 16, 20, 24.
- Controls at least 26 px high; popover rows 26 px; settings rows 8 px vertical padding.
- Radii: `kbd` 4, control 6 (fields, buttons, rows), card 8, window and popover 12 (inkuno `sheet`),
  HUD notch 0 0 18 18 (bottom corners), HUD cursor 14.
- Shadows: popover `0 1px 3px rgba(0,0,0,.05)` and `0 8px 24px rgba(0,0,0,.10)` in both
  palettes (inkuno `popover_shadow`); HUD `0 6px 20px rgba(0,0,0,.28)` (inkuno `floating`).

### 1.4 Motion

| Token | Duration | Use |
|--|--|--|
| `fast` | 90 ms | level bars (redraw) |
| `base` | 180 ms | HUD show and hide, popover open |
| `slow` | 350 ms | window move when the app places a window |
| `pulse` | 800 ms | menu bar icon while loading, opacity 1 to 0.35 |
| `spin` | 600 ms | HUD decoding spinner |

Easing: ease-out in, ease-in out. The HUD fades in and moves 6 px down (notch and cursor).

## 2. Menu bar icon

Glyph: five bars, 18 × 14 pt, stroke 1.8, round caps (as `prototypes/v3.html`). Idle is drawn in the
menu bar's ink colour. The listening colours need a non-template image (§12).

| State | When | Glyph | VoiceOver label |
|--|--|--|--|
| `idle` | nothing running | bars in the menu bar colour; at 40 % opacity when the model is not in memory | `Jisuno, idle` |
| `listening-dictate` | a dictation or hands-free session is recording | bars in `dictate_text` | `Jisuno, dictating` |
| `listening-command` | a command hold is recording | bars in `command_text` | `Jisuno, command` |
| `loading` | model load running | `idle` glyph, pulsing (`pulse`) | `Jisuno, loading model` |
| `error` | an error from §8 is active | `idle` glyph with the warning badge | `Jisuno, needs attention` |

Badges (9 × 9 pt, bottom right of the glyph; lock sits left of the warning when both show):

| Badge | Shown while | Fill | Label suffix |
|--|--|--|--|
| lock | Secure Input is on | `text` | `, secure input on` |
| warning | an §8 error is active (invalid config, permission off, no mic, model missing) | `warning` | `, needs attention` |

Click opens the popover (§4). The icon label changes with state; the badge also reads in the popover.

## 3. HUD

### 3.1 Position

Key: `settings.json` `hud`.

| Value | Placement | Notes |
|--|--|--|
| `notch` (default) | hangs from the bottom edge of the notch, centred; on a Mac without a notch, under the menu bar, centred | top padding comes from the screen's safe-area inset, not a constant |
| `cursor` | 24 px below the mouse pointer, centred | pointer, not text caret (§12) |
| `off` | not drawn | tones and the icon still work; failures show in the popover and the icon badge |

### 3.2 Timing

| Rule | Value |
|--|--|
| HUD appears after a hold has lasted | 150 ms (`keybindings.md` §4) |
| Release before 150 ms (a tap) | no HUD, no tone, no transcription; a model load started by this press is cancelled |
| Show and hide | `base` (180 ms) |
| Level bars redraw | `fast` (90 ms) |
| Partial text update | as the decoder returns it, only when warm |
| Countdown | from elapsed 1:45 (`COUNT_AT`) |
| One HUD state at a time | a new state replaces the old one. A hold in progress is never replaced: a config error that arrives during a hold is not drawn in the HUD; the icon badge and the Files pane show it until the file is fixed. |
| Tones (`sounds: true`) | start dictate 880 Hz, start command 660 Hz, stop dictate 1320 Hz, stop command 990 Hz, cancel 300 Hz; 60 ms each |

### 3.3 States

The layout is one row (mode, bars, meta) plus an optional line. Meta is `micro` or `mono`.

| # | State | Trigger | Exact copy | Dismiss |
|--|--|--|--|--|
| H1 | Listening, dictate | hold Right ⌥ past 150 ms; or ⌃⌥Space | `Dictate` · bars · `esc to cancel`; hands-free: `hands-free · esc to cancel` | key-up (or toggle again); Esc cancels |
| H2 | Listening, command | hold Right ⌘ past 150 ms | `Command` · bars · `esc to cancel` | key-up; Esc cancels |
| H3 | Model loads under speech | hold while the model is not warm | thin 3 px load bar, meta `loading model while you speak` | removed when warm |
| H4 | Live partial text | warm model and `partials: true` | words so far, then `▍`; before the first word, `listening…` in `soft` | with the utterance |
| H5 | Countdown | elapsed 1:45 of a dictation or hands-free session | meta `0:15 left` (mono), counting to `0:00` | at 2:00 the HUD stops and transcribes as if released |
| H6 | Decoding | key-up or hands-free end | mode · spinner · `decoding`; `finishing model load` while still loading | the result |
| H7 | Inserted | dictation inserted | chip `Inserted 9 words` (word count of the text); `<n> ms` after it only if `hud.show_latency` | 1.2 s |
| H8 | Ran command | command steps all succeeded | chip `Ran "start working"` | 1.3 s |
| H9 | Cancelled | Esc while listening or confirming | chip `Cancelled`; nothing inserted, nothing run | 0.7 s |
| H10 | Confirm prompt | a command with `confirm: true` | `Run "clean build"? cargo clean · Return to run · Esc to cancel` | Return runs (H8); Esc cancels (H9); 6 s with no answer shows `Not run` for 1.0 s |
| H11 | No match | matcher finds nothing close enough | `Did you mean "start working"?` (plain text); nothing runs | 2.5 s |
| H12 | Step failure | a step fails; earlier steps stay done | chip `Step 2 of 3 failed: window.tile · no window "terminal"` | 4 s; Recent row tagged `failed` |
| H13 | Config error | a file fails validation on reload | chip `keybindings.json:12: unknown key "hald" · using last good config` | shown once, 6 s; icon warning badge stays until a valid reload |
| H14 | Focus lost | the app that had focus at key-down quit, or its window closed before key-up | chip `Focus lost: text in Recent` | 4 s; Recent row tagged `not inserted` |
| H15 | Secure input | a hold or key while Secure Input is on | chip `Secure input on (<app>) · keys paused` | 3 s; once per app per session; lock badge stays while on |
| H16 | Bluetooth mic | first utterance on a Bluetooth input in a session | note `Bluetooth mic: lower quality, more latency` under the listening row | once per session |
| H17 | Missing device | `input_device` names a device not connected | note `Mic "<name>" not found · using system input` | each utterance until fixed |
| H18 | Model ready | load finished with no hold running | chip `Model ready` | 0.9 s |

Copy marked *new* in §7, and H16 and H17, approved in round 6.

## 4. Popover

Opens from the icon. Width 310 pt, padding 6, popover shadow, `popover` fill, `micro` section labels.

| Row | Shows | Action |
|--|--|--|
| Header | `Jisuno`; the model name `parakeet-tdt-0.6b-v3-int8`; state dot | none |
| Model | `Warm · ~0.9 GB · unloads in 10 min`, or `Not loaded · loads on first use`, `Loading…`, `Not downloaded` | `Warm model` (shows `⌃⌥W`) / `Unload model` / `Download model` |
| Permissions | `Microphone`, `Accessibility`, `Input Monitoring`, each `Allowed` (`ok`) or `Not allowed` (`warning`) | a row not allowed opens its System Settings pane (§6) |
| Secure input | only while on: `Secure input on (<app>) · keys paused` (`caution`) | none |
| Recent | last 5 results, memory only: text, tag `failed` / `not inserted` where set; `Nothing yet.` when empty | click copies the text (`Copied` toast) |

| `Settings…` | `⌃⌥,` | opens Settings |
| `Quit Jisuno` | `⌘Q` | quits |

`unloads in N min` shows the `unload_after_idle_min` value; `0` shows `stays loaded`.
Recent shows commands too, as `⌘ start working`.

### 5.1 Keybindings (`keybindings.md` §9)

- Table: Command (file id, mono) · Key · When · Hold · action. All nine commands are listed; a command without a binding shows `Not set`.
- Click the key cell: it shows `Press keys…` (button in `dictate_text` outline).
- Press the chord (or hold one right-side modifier for a hold binding). The cell shows the display form live: `⌃⌥⇧⌘`, `Right ⌥`.
- Esc alone cancels the recording; the old binding stays.
- Conflict, inline under the row: `Taken by <command> (<when>)` with buttons `Replace` and `Cancel`. Replace rebinds and leaves the other command `Not set`.
- Errors, inline under the row (`caution`), from `keybindings.md` §7: the messages as written there.
- Warnings, inline under the row (`warning`), from `keybindings.md` §8: `Warning: "<key>" is a common app shortcut (<name>) · apps will stop getting it`. The binding is saved.
- Save is immediate. A failed write keeps the last good file and shows the message.
- `Set to default` restores the default for that command; a conflicting binding is handled as in Replace.

## 6. Welcome window (first run)

First run is detected as: `~/.config/jisuno/settings.json` does not exist (§12). Window 540 × 580, title `Welcome to Jisuno`.

1. **Config files.** Written first, before anything else: `settings.json`, `keybindings.json`, `theme.json`, `voice-control-config.json`, each with every key at its default, and `schemas/` (`jisuno.md` §10.4). Shown as `Written to ~/.config/jisuno/`.
2. **Permissions.** Live: the window re-checks every second and on focus. Each row: name, reason, status, and the button.

| Permission | Reason (caption) | Pane (`x-apple.systempreferences:com.apple.preference.security?…`) |
|--|--|--|
| Microphone | `Records only while you hold a key.` | `Privacy_Microphone` |
| Accessibility | `Inserts text and moves windows.` | `Privacy_Accessibility` |
| Input Monitoring | `Lets the hold keys work in every app.` | `Privacy_ListenEvent` |

Status `Allowed` (`ok`) or `Not allowed` (`warning`); button `Open System Settings`. Pane links are unverified on macOS 27.3 (§12).
3. **Speech model.** `Parakeet TDT 0.6B v3, int8 · about 650 MB`, button `Download`, progress `Downloading 42% · 273 of 650 MB` with a bar (`dictate_text`), then `Downloaded` (`ok`). Caption: `Dictation works once the download finishes.`

Footer: `Start Jisuno` (primary) is enabled when all three permissions are `Allowed`. Otherwise the caption `Allow the three permissions to start.` shows. Starting does not wait for the model.

## 8. Accessibility

| Area | Rule |
|--|--|
| Icon | VoiceOver label per state (§2), updated on every state change. |
| HUD | role `status`, polite live region. The text of the state is the announcement. Level bars are decorative (hidden). The countdown is announced once, at `0:15 left`. |
| Keybinding recorder | `Press keys…` announced on start; the recorded chord announced on save; a conflict announced with its `Taken by` line. |
| Popover | every row is a button or a labelled item; the chord is read as words (`control option comma`). Esc closes. |
| Settings | every control reachable by Tab, labelled by its row label; Keybindings rows read as one line each. |
| Reduce Motion | the HUD fades without the slide; the loading pulse stops at 60 % opacity; the decoding spinner stops turning (the `decoding` text stays); level bars still move, since they show input. |
| Contrast | text 4.5:1 on its ground (§1.1); non-text 3:1: `dictate` 3.57 on white, `command` is never used alone on light; `command_text` carries the light command mode. |
| Colour | mode is always also a word (`Dictate`, `Command`) and a glyph state; a badge always has a row in the popover that names it. |
| Targets | popover rows at least 26 pt high; controls at least 26 pt. |

- Fonts: macOS system fonts, nothing bundled (§1.2).
- `cursor` HUD position is the mouse pointer, not the text caret.
- First run is detected by a missing `~/.config/jisuno/settings.json`.
- Mic does not open when the model is missing or no mic is present; the HUD says so after the 150 ms hold.
- `theme.json` `appearance`: `system` follows macOS; `fixed` uses `name`. Theme names `quiet-light`, `quiet-dark`.
- With `hud: off`, failures show only in the popover and icon badge; no HUD line.
- Recent rows copy on click. Recent holds commands too, tagged `failed` when a step fails.
- Popover shows model and permissions and no workspace starter (v2 had one; the brief does not list it).
- Settings shows Commands and Workspaces read-only; the file is the source (`jisuno.md` §1: "a view over them").
- `Set to default` per command; no global reset.
- Pane deep links (`Privacy_Microphone`, `Privacy_Accessibility`, `Privacy_ListenEvent`) are unverified on macOS 27.3; check before the Welcome window is built.
- Tones: the v2 frequencies, not measured.
- Notch HUD on a Mac without a notch: under the menu bar, centred (the same as the notch placement).
- Popover footer caption `Recent is kept in memory until you quit` is new copy, approved in round 6.
- Menu bar icon: listening colours on a non-template image (macOS draws template icons in the menu bar ink). Check on the reference Mac.
- New copy approved in round 6: the *new* strings in §7, H16, H17, the Bluetooth warning, the popover footer caption, and the Welcome captions (`Checked live…`, `Written to ~/.config/jisuno/`).
